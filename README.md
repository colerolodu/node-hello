# Aviso

Antes de mais nada: o conteúdo aqui foi produzido acompanhando um curso aberto. O material original não é meu e não pode ser redistribuído como se fosse.

Quem quiser estudar o assunto deve procurar o curso na plataforma de origem. Se um dia ele mudar de formato ou passar a cobrar, não tenho ingerência sobre isso — o material em si continua excelente.

[![Acesso pela plataforma](https://img.shields.io/badge/abrir%20na%20plataforma-E94D5F?style=for-the-badge)](#)

O exercício cobre o caminho completo: duplicar o repositório, criar um ramo, fazer a alteração e abrir a proposta de contribuição.

### O que está incluído

- Um guia escrito, em etapas, partindo do zero.
- Um arquivo de exemplo para treinar a primeira contribuição.
- Modelo de mensagem de commit, seguindo o padrão mais usado.

### Como praticar

1. Duplique este repositório para a sua conta.
2. Crie um ramo com um nome descritivo.
3. Edite o arquivo de exemplo com o seu nome ou uma melhoria qualquer.
4. Envie o ramo e abra a proposta de contribuição.

Depois de aprovado, o seu nome passa a fazer parte do histórico — e é assim que se aprende o fluxo real.
